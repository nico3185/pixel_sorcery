PixelSorcery

Sega Mega Drive / Genesis games rebuilt as native programs: decompiled, recompiled to C, and run on their own video, sound and input code, with no emulator in the loop.

Download for Mac Download for Linux (.deb) Source on GitHub

Mac: macOS 14+ on Apple silicon, unsigned (System Settings → Privacy & Security → Open Anyway) · Linux: Debian / Ubuntu, sudo apt install ./pixelsorcery_0.1.0_all.deb, then pixelsorcery · no ROMs included

How it works

  1. Point it at your own dumps. PixelSorcery recognises each game by its checksum.
  2. Recompile. The 68000 game code and the Z80 sound driver are translated to C.
  3. Build. That C is compiled with the native runtime into a program for your computer.
  4. Play. Widescreen, instant save states, controller mapping and a settings menu come with it.

Checked against the original

Every poll. Recorded play sessions and full-game input recordings are replayed on the port and on Genesis Plus GX. Work RAM must match at every controller poll.
Mixed runs. The same replays run again with part of the code in a 68000 interpreter, which proves the hand-over between compiled and interpreted code is exact.
Measured coverage. How much of each game's code has run in a verified replay is measured per title, and level-select recordings push it further.

Game coverage

Share of each game's code that has run in a replay verified against the original (31 October 2026). Reachable counts the code the game can actually run: functions that ran, plus everything their code calls or jumps to. All code also counts leftover routines nothing calls. Code that hasn't run yet still works: it falls back to the built-in 68000 interpreter, so lower coverage costs speed, not correctness.

Native, no emulation

68000 and Z80: recompiled C.
Video (VDP): its own renderer, with Metal on macOS.
Sound (YM2612 + PSG): its own synthesis.

No game included

PixelSorcery ships no ROMs and no code or data made from them. Every game is built on the player's machine, from a dump of a cartridge they own. Free for non-commercial use (PolyForm Noncommercial).

PixelSorcery is a hobby project, unaffiliated with any game publisher. · github.com/nico3185/pixel_sorcery
